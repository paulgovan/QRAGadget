## Package Overview

**QRAGadget** is an R package providing a Shiny Gadget for interactive Quantitative Risk Analysis (QRA) visualizations. Users upload raster data (CSV/TSV) or select an R data.frame, configure bins and display options, and export a standalone leaflet HTML map.

Two exported functions:
- `QRAGadget()` — launches the Shiny gadget
- `matrixInput()` — editable matrix input widget (adapted from deprecated shinyIncubator)

## Architecture

### Source files (`R/`)

- **`R/QRAGadget.R`** — the main gadget. Contains:
  - `labelFormat2()`: internal helper for scientific-notation legend labels (critical for small QRA values like 1e-16)
  - Hardcoded `sample` matrix and `initBins` vector used as defaults when no file is uploaded
  - Shiny UI with four tabs: Input/Output, Raster, Map, Preferences
  - Server logic: reactive raster computation, colorBin palette, leaflet map rendering, HTML export
  - URL bookmarking enabled via `enableBookmarking(store = "url")`

- **`R/tableinput.R`** — `matrixInput()` widget. Relies on companion JS/CSS in `inst/tableinput/`.

### Key data flow

1. User uploads CSV/TSV **or** picks an R data.frame → parsed to matrix
2. Matrix is converted to a `raster::raster` object, flipped (y-direction), optionally disaggregated (bilinear), zeros replaced with `NA`
3. A `colorBin` palette is applied using the configurable bin breakpoints from the matrix input widget
4. Leaflet map rendered; user can export as standalone HTML

### Static assets (`inst/`)

- `rstudio/addins.dcf` — registers `QRAGadget()` as an RStudio Addin
- `tableinput/tableinput.js` + `tableinput.css` — required by `matrixInput()`
- `images/` — screenshots used in documentation/vignette

## CI/CD

Three GitHub Actions workflows:
- **R-CMD-check** — runs on macOS/Windows/Ubuntu across R release, devel, oldrel-1
- **pkgcheck** — ropensci quality checks on pushes to master
- **pkgdown** — builds and deploys the documentation site to gh-pages

All documentation (`.Rd` files, `NAMESPACE`) is generated by roxygen2 — edit only the roxygen2 comments in source, then run `devtools::document()`.
