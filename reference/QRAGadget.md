# A 'Shiny' Gadget for Interactive QRA Visualizations.

Upload raster data and easily create interactive QRA visualizations.
Select from numerous color palettes, basemaps, and different
configurations.

## Usage

``` r
QRAGadget()
```

## Value

The function launches a Shiny Gadget.

## Examples

``` r
if (interactive()) {
  QRAGadget::QRAGadget()
}
```
